# 03 — CIS Macro Analytics: digitalisation and macro trends

## Исследовательский вопрос

Как менялись доступ к интернету и отдельные макроэкономические показатели России, Казахстана, Беларуси, Узбекистана, Армении и Кыргызской Республики? Как различается полнота покрытия показателей и периодов?

## Источник и лицензирование

World Bank Indicators API v2, World Development Indicators (source ID 2). API позволяет получать временные ряды программно без API-ключа. Запросы выполняются с пагинацией; исходные JSON-страницы каждого индикатора сохраняются локально вместе с датой извлечения.

- Документация API: https://datahelpdesk.worldbank.org/knowledgebase/articles/889392
- Базовая структура запросов и пагинация: https://datahelpdesk.worldbank.org/knowledgebase/articles/898581
- Метаданные источника WDI: https://datahelpdesk.worldbank.org/knowledgebase/articles/1886695
- Лицензии каталога данных: https://datacatalog.worldbank.org/public-licenses

Для собственных наборов данных World Bank стандартно применяется CC BY 4.0, однако условия нужно проверять по метаданным конкретного ряда и его первоисточнику. Атрибуция и дата выгрузки обязательны.

## Страны и индикаторы

Коды стран: RUS, KAZ, BLR, UZB, ARM, KGZ. Период по умолчанию: 2000–2024. Его можно изменить через переменные окружения WB_START_YEAR и WB_END_YEAR.

| Код | Индикатор | Единица |
|---|---|---|
| NY.GDP.PCAP.CD | GDP per capita, current US$ | текущие доллары США на человека |
| IT.NET.USER.ZS | Individuals using the Internet | % населения |
| FP.CPI.TOTL.ZG | Inflation, consumer prices | годовое изменение, % |
| SL.UEM.TOTL.ZS | Unemployment, total, modeled ILO estimate | % рабочей силы |

## Методология

1. Получить все страницы API по каждому индикатору с повторными попытками при 429/5xx и временных сетевых сбоях.
2. Сохранить исходный JSON и дату извлечения, преобразовать показатели в длинную таблицу country × year × indicator.
3. Построить полную сетку стран и лет. Отсутствующие наблюдения остаются NULL — никакой интерполяции и gap-fill.
4. Проверить дубликаты country-year-indicator, полноту по каждому индикатору и число парных наблюдений для корреляций.
5. Рассчитать первое и последнее доступное значение, абсолютное и относительное изменение. Последний год может отличаться между странами и показателями.
6. Рассчитать Pearson correlation на парных доступных наблюдениях. Корреляция — описательная ассоциация, а не причинный эффект.
7. Сформировать CSV, DuckDB, quality report и Plotly HTML dashboard.

## Запуск

Из корня репозитория:

    pip install -r requirements.txt
    python projects/03_cis_macro_analytics/run.py

Настройка периода:

    # Linux/macOS
    WB_START_YEAR=2000 WB_END_YEAR=2024 python projects/03_cis_macro_analytics/run.py

PowerShell:

    $env:WB_START_YEAR="2000"
    $env:WB_END_YEAR="2024"
    python projects/03_cis_macro_analytics/run.py

## Результаты

- macro_panel.csv — полная панель по странам и годам;
- indicator_long.csv — исходные непустые наблюдения;
- indicator_trends.csv — первое/последнее доступное значение и изменение;
- latest_snapshot.csv — последняя доступная точка для каждой страны и серии;
- indicator_correlations.csv — парные Pearson correlations;
- correlation_pair_counts.csv — число совместных наблюдений для каждой пары индикаторов;
- quality_report.json — время выгрузки, объём и пропуски;
- cis_macro.duckdb — таблицы для SQL;
- dashboard.html — графики по всем индикаторам.

## Ограничения

- World Bank может пересматривать исторические значения; дата извлечения и raw JSON нужны для воспроизведения конкретного снимка.
- Данные по странам и индикаторам публикуются с разной периодичностью и лагом.
- GDP per capita в текущих USD зависит от курса и цен; это не темп реального экономического роста.
- Безработица — модельная оценка ILO, а не количество зарегистрированных безработных.
- Неодинаковое покрытие может смещать сравнения; пропуски не заполняются.
- Корреляция между интернет-проникновением и GDP per capita не доказывает причинность.
- Страновой уровень агрегирования не позволяет делать выводы о конкретных людях или домохозяйствах.

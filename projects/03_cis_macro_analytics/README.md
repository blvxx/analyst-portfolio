# 03 — CIS Macro Analytics: digitalisation and macro trends

## Исследовательский вопрос

Как менялись доступ к интернету и отдельные макроэкономические показатели в России, Казахстане, Беларуси, Узбекистане, Армении и Кыргызской Республике в 2000–2024 годах? Какие периоды и страны имеют пропуски в наблюдениях, и насколько осторожно нужно интерпретировать сопоставления?

## Источник данных

World Bank Indicators API v2, источник World Development Indicators (source=2). Данные запрашиваются напрямую по официальному API, без авторизации. Для собственных наборов данных Всемирного банка стандартной лицензией обычно является CC BY 4.0; условия конкретного ряда следует проверять в метаданных, поскольку Всемирный банк также распространяет некоторые внешние наборы на иных условиях.

API и документация:
- https://api.worldbank.org/v2/
- https://datahelpdesk.worldbank.org/knowledgebase/articles/889392
- https://datahelpdesk.worldbank.org/knowledgebase/articles/898581
- https://datacatalog.worldbank.org/public-licenses

Запрашиваемые индикаторы:
- NY.GDP.PCAP.CD — GDP per capita (current US$);
- IT.NET.USER.ZS — Individuals using the Internet (% of population);
- FP.CPI.TOTL.ZG — Inflation, consumer prices (annual %);
- SL.UEM.TOTL.ZS — Unemployment, total (% of total labor force), modeled ILO estimate.

Коды стран: RUS, KAZ, BLR, UZB, ARM, KGZ. Период по умолчанию: 2000–2024.

## Методология

1. Получить отдельный ответ API для каждого индикатора, сохранить исходный JSON и дату извлечения.
2. Преобразовать наблюдения к длинной таблице country × year × indicator.
3. Построить полную сетку стран и лет, чтобы явно показать отсутствующие наблюдения.
4. Сформировать панель в wide-формате, таблицу последних доступных наблюдений и изменение между первым и последним доступными значениями.
5. Рассчитать попарные корреляции только по доступным наблюдениям. Корреляция не трактуется как причинный эффект.
6. Не интерполировать, не заполнять и не экстраполировать пропуски.
7. Сформировать DuckDB, CSV, quality report и Plotly HTML dashboard.

## Запуск

Из корня репозитория:

    pip install -r requirements.txt
    python projects/03_cis_macro_analytics/run.py

По умолчанию запрашиваются 2000–2024 годы. Диапазон можно переопределить переменными окружения WB_START_YEAR и WB_END_YEAR.

## Результаты в outputs

- macro_panel.csv — панельная таблица по стране и году;
- indicator_long.csv — длинный набор исходных наблюдений;
- indicator_trends.csv — первые/последние доступные годы и абсолютное изменение;
- latest_snapshot.csv — последнее ненулевое наблюдение каждого индикатора по стране;
- indicator_correlations.csv — корреляции по полным парам наблюдений;
- quality_report.json — дата извлечения, объём и пропуски;
- cis_macro.duckdb — SQL-таблицы;
- dashboard.html — интерактивные графики.

## Ограничения и осторожность

- Значения World Bank могут пересматриваться; одинаковый запуск в разные даты может дать разные результаты. В metadata фиксируется время выгрузки, а raw JSON сохраняется для воспроизводимости конкретного снимка.
- Последний доступный год может отличаться между странами и индикаторами.
- GDP per capita в текущих долларах США зависит не только от реального роста, но также от инфляции и валютного курса. Его нельзя трактовать как показатель реального роста без дополнительных рядов в постоянных ценах.
- Безработица — модельная оценка ILO, а не прямая регистрационная статистика.
- Пропуски не заполняются; сравнения должны учитывать неодинаковую доступность данных.
- Корреляция между интернет-проникновением и GDP per capita не доказывает, что одно вызывает другое.
- Страна и год — агрегированный уровень; проект не позволяет делать выводы об отдельных людях или домохозяйствах.
